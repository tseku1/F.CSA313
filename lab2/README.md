## Дүн шинжилгээ

- **Нийт амжилт:** Бүх хүсэлтүүд `200 OK` кодтой амжилттай ажилласан, алдаа гараагүй.  
- **GET хүсэлтүүдийн ялгаа:**
  - `parliament tuuhen-tovchoon` болон `namtar` → дунджаар 70–80ms орчим, тогтвортой.  
  - `hitech-Intel Core i9` → хамгийн удаан (773ms дундаж, 3866ms хамгийн их), серверийн ачаалалд мэдрэмтгий.  
  - `getJSON` → хамгийн хурдан (17ms дундаж).  
- **POST / PUT / DELETE:**
  - `CreateUser (POST)` → дунд зэргийн хурдтай (284ms).  
  - `Update (PUT)` → тогтвортой (273ms, бага хэлбэлзэл).  
  - `Delete (DELETE)` → хамгийн хурдан (14ms).  
- **Throughput:** Нийт 31.7 хүсэлт/секунд — 10 хэрэглэгчийн нөхцөлд тогтвортой.  
- **Хэлбэлзэл:** `hitech-Intel Core i9` хамгийн өндөр Std. Dev (646.54).

1. Систем бага хэрэглэгч (10 threads) дээр тогтвортой, бүх хүсэлтүүд амжилттай.
